# Security policy

## Scope

Educational portfolio project; no formal security audit has been performed.

## Reporting

Do not publish credentials, private customer data, or exploit details in public issues. Contact the maintainer privately through the method on their GitHub profile.

## Safe publication

- Never commit credentials, `.env` files, private customer data, raw data without redistribution permission, or generated artifacts.
- Keep local datasets, model artifacts, caches, and virtual environments out of Git.
- Review staged changes before every public push.

## Model artifacts

Joblib uses pickle serialization; loading an untrusted artifact can execute arbitrary code. Only load artifacts generated by your own trusted run. Artifacts may be incompatible across library versions.

## Responsible use

Predictions are probabilistic estimates, not explanations or guarantees. Evaluate fairness, calibration, drift, and customer impact before operational use.
